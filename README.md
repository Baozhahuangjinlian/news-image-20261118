A one-day newspaper front page summing up the world's news of Wednesday 18 November 2026: the Crimea bridge partially collapses in a drone attack; US strikes on Qeshm draw Iranian drone attacks on Bahrain and Kuwait; Trump, Xi and Putin meet in Shenzhen; the US loses its measles-free status after 26 years; Ebola in the DRC; and sliding markets. The front page is composed with PIL from a generated lead illustration plus real headlines, set in large type so it stays legible at about 300 pixels across.

## Run it

```sh
python3 main.py
```

`main.py` copies `entry.png` (1024x1024, the front page) to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset). It runs with no network and writes the same bytes on every run.
